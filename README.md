# AI Data Analysis System

An AI-powered data analysis web application that allows users to analyze CSV datasets using natural language questions.

## 🚀 Features

- Upload and analyze CSV datasets
- Automatic data cleaning
- Handle missing values and duplicate records
- Generate statistical summaries
- Ask questions about the dataset using natural language
- AI-powered analysis using Google Gemini
- Sales and business insights
- Detect anomalies
- Interactive dashboard
- Flask REST API
- Multiple-question analysis
- Dashboard filtering

## 🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Flask
- Google Gemini API
- HTML
- CSS
- JavaScript
- Jupyter Notebook

## 📊 Example Analysis

The system can answer questions such as:

- What is the total sales?
- What is the average sale?
- What is the highest sale?
- How many transactions are there?
- Show sales by city.
- Which product line has the highest sales?
- Show sales by gender.
- Find unusual or anomalous values.
